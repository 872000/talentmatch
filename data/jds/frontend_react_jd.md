# Frontend Developer (React) — BrightCart

**Location:** Remote (Canada) · **Type:** Full-time

## About the role
BrightCart needs a frontend developer to own our React storefront. You'll ship
single page application features with TypeScript, style with Tailwind CSS, and
keep quality high with Jest and Cypress.

## Requirements
- 2+ years with React, TypeScript, and Redux.
- Tailwind CSS and responsive design; Figma handoff experience.
- Testing: Jest unit tests and Cypress e2e.
- Next.js experience; Vite builds.
- Git and Agile collaboration.

## Nice to have
- Sass, HTML/CSS fundamentals, GitHub Actions.
